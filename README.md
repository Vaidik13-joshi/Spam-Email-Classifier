# Spam-Email-Classifier
Email spam classifier built using TF-IDF vectorization and Naive Bayes algorithm to convert text data into numerical features and accurately classify emails as spam or not spam.

This project detects whether an email is spam or not using machine learning.

Features

- Spam detection
- TF-IDF vectorization
- Naive Bayes algorithm

How to Run

1. Install libraries:
   pip install scikit-learn pandas

2. Run:
   python spam_classifier.py
